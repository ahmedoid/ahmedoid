# Profile README "Superpower" Upgrade — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the current `README.md` with a portfolio-style "superpowered" profile that adds a typing header, pinned-repo grid, unified `tokyonight` stats, trophies, activity graph, and a Spotify placeholder — while preserving the hourly blog-post workflow and the snake SVG.

Pin cards use `gh-card.dev` (the official github-readme-stats Vercel deployment was paused — see spec addendum). The existing `<!-- BLOG-POST-LIST:START -->` / `<!-- BLOG-POST-LIST:END -->` markers are preserved untouched so `blog-post-workflow.yml` keeps writing between them.

**Tech Stack:** GitHub-flavored Markdown · HTML `<img>` embeds · `readme-typing-svg.demolab.com` · `gh-card.dev` · `streak-stats.demolab.com` · `github-profile-trophy.vercel.app` · `github-readme-activity-graph.vercel.app` · `shields.io` · `spotify-github-profile.kittinan.com` · `lowlighter/metrics` GitHub Action.

## Task 2a: Add the metrics GitHub Action workflow

**Files:**
- Create: `.github/workflows/metrics.yml`

- [ ] **Step 1: Create `.github/workflows/metrics.yml` with the following content**

```yaml
name: Metrics
on:
  schedule:
    - cron: '0 * * * *'    # hourly
  workflow_dispatch:
  push:
    branches: [main]
permissions:
  contents: write
jobs:
  github-metrics:
    runs-on: ubuntu-latest
    steps:
      - uses: lowlighter/metrics@latest
        with:
          token: ${{ secrets.METRICS_TOKEN }}
          filename: github-metrics.svg
          user: ahmedoid
          template: classic
          base: header, activity, community, repositories, metadata
          base_indepth: false
          config_timezone: Asia/Riyadh
          plugin_languages: yes
          plugin_languages_ignored: html, css, scss
          plugin_languages_details: percentage
          plugin_languages_indepth: yes
          plugin_languages_limit: 8
          plugin_lines: yes
          plugin_topics: yes
          plugin_topics_mode: icons
```

- [ ] **Step 2: Verify the workflow file is valid YAML**

Run:
```bash
python -c "import yaml; yaml.safe_load(open('.github/workflows/metrics.yml'))" && echo "YAML OK"
```
Expected: `YAML OK`.

- [ ] **Step 3: Document the required secret in a top-level note inside the workflow**

The workflow needs a `METRICS_TOKEN` repository secret (a fine-grained or classic PAT with `public_repo` read access). The user must add this once at `https://github.com/ahmedoid/ahmedoid/settings/secrets/actions/new`. Until they do, the workflow will fail on its first run — but that does not break the README rendering, because the embedded `github-metrics.svg` will simply not yet exist and GitHub will show a broken-image placeholder for that one section.

Add a hidden HTML comment in `README.md` (in Task 2b) above the metrics embed explaining this one-time setup.

- [ ] **Step 4: Commit**

Run:
```bash
git add .github/workflows/metrics.yml
git commit -m "ci: add lowlighter/metrics workflow to generate github-metrics.svg"
```
